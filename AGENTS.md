## Environment and commands

- WSL with system Python 3.12.3. All needed packages (numpy 2.4.4, pandas 3.0.2, scipy 1.17.1, scikit-learn 1.8.0, lightgbm 4.6.0, catboost 1.2.10) are already installed system-wide; no pip install needed. `/home/oluhle/.venvs/sasol-oct14` is an equivalent system-site-packages venv.
- Do not use `.venv313/` from WSL: it is a Windows venv (`Scripts/*.exe`). `requirements-py313.txt` is UTF-16LE CRLF (PowerShell `pip freeze`); decode before reading or editing.
- Run from repo root, single-threaded, e.g.:
  `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MPLCONFIGDIR=/tmp/sasol-mpl python3 -u experiments/oct10/run_experiment.py`
  `python3 -B -u experiments/next_round/run_round.py --phase all`
- Fits are long (next_round enforces a 1-hour budget) and run sequentially. Reuse caches under `outputs/` (`outputs/oct10/panel.pkl`, `*_pred.csv`, `*.npy`); never delete `outputs/`, and do not rerun accepted baselines.
- No tests, CI, Makefile, or linter. Verification is experiment gates plus `*_decision.json` / `*_comparison.csv` audit files.

## Research protocol (repo-specific rules)

- Pre-register the hypothesis and numerical acceptance gate before fitting; write proposal/decision JSON under `outputs/<round>/`. Never relax a gate after seeing results.
- Temporal/purged validation only; no random CV and no labels leaking across origins. March 2025 is the tuning fold; June/September 2025 are evaluation folds and must not be used for tuning multipliers or thresholds.
- Change one submission component at a time and preserve non-selected columns from the current best CSV. Baseline snapshots (`outputs/oct10/baseline_*.csv`, `confirmed_*_baseline.json`) are immutable; rejected experiments never overwrite them.
- Exports must keep the 5,488 official IDs in sample order, finite nonnegative CLV values, and configured labels; existing exporters hash the source baseline and record changed-row counts.
- Evidence goes to gitignored `outputs/`; curated copies are committed (e.g. `docs/oct14_evidence/`). Commit messages are phase-prefixed: "Pre-register X experiment", "Record X results", "Complete Phase ...".
- `configs/final_model_spec.json` (FROZEN) and `src/phase0*` are the original quarterly pipeline that produced S0 (public 0.289392053). Do not modify or retrain it; new work belongs in `experiments/`.
- `top4_papers/`, `top4_shipped/`, `top4_submission/` are closed Sep 28-29 side explorations whose exports scored below baseline; each README records its outcome at the end.
